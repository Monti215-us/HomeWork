### Задание 2

Проведите сканирование Metasploitable в режимах SYN, FIN, Xmas, UDP.

Запишите сеансы сканирования в Wireshark.

Ответьте на следующие вопросы:

- Чем отличаются эти режимы сканирования с точки зрения сетевого трафика?
- Как отвечает сервер?

*Приведите ответ в свободной форме.*

### Ответ 2
- Режими сканирования отличаются TCP флагами и ответами сервера. 
- В Wireshark эти различия можно увидеть по установленным TCP-флагам. 
При SYN сканировании - отправляется TCP пакет с флагом SYN. Открытые порты отвечаюь SYN/ACK, закрытые - RST
FIN-сканирование отправляет пакеты с флагом FIN. Закрытые отвечают RST, а открытые не отвечают. 
XMAS- сканирование отправляет пакеты с флагами FIN, PSH и URG. Закрытые отвечают RTS, а открытые не отвечают. 
UDP - сканирование отправлет UDP пакеты. Закрытый UDP-порт может ответить ICMP-сообщением Destination Unreachable (Port Unreachable), а открытый порт может ответить UDP-пакетом или не ответить вовсе.
